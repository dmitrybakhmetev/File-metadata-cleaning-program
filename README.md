# File Metadata Cleaning Program 🛡️

Консольная утилита (CLI) на Python для безопасного и быстрого удаления скрытых метаданных из изображений, PDF-файлов и документов Word.

---

## 🚀 Возможности

Утилита поддерживает очистку следующих форматов:

### 🖼️ Изображения

Поддерживаются форматы:

* `.jpg`
* `.jpeg`
* `.png`

Удаляются EXIF-данные, включая:

* дату и время съёмки;
* геолокацию;
* модель камеры;
* производителя устройства;
* другие встроенные метаданные изображения.

### 📄 PDF-документы

Поддерживается формат:

* `.pdf`

Утилита очищает скрытые свойства документа, включая:

* автора;
* производителя;
* создателя;
* метаданные документа;
* служебную информацию страниц.

### 📝 Документы Word

Поддерживается формат:

* `.docx`

Очищаются встроенные свойства документа:

* автор;
* название;
* ключевые слова;
* тема;
* комментарии;
* информация о редакции;
* другие свойства документа.

## 🛠️ Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/dmitrybakhmetev/File-metadata-cleaning-program.git
cd File-metadata-cleaning-program
```

### 2. Создание виртуального окружения

#### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

Используйте файл `requirements.txt` для установки всех необходимых библиотек:

```bash
pip install -r requirements.txt
```

---

## 💡 Использование

Запустите программу через терминал, передав путь к файлу в качестве аргумента:

```bash
python main.py path/to/your/file.jpg
```

Пример для PDF-файла:

```bash
python main.py document.pdf
```

---

## 📤 Сохранение результата

Вы можете указать собственный путь для сохранения очищенного файла с помощью параметра `-o` или `--output`:

```bash
python main.py document.pdf -o safe_document.pdf
```

Если выходной файл не указан, программа автоматически сохранит очищенную версию в той же папке.

Например:

```text
document.jpg
```

будет преобразован в:

```text
cleaned_document.jpg
```

## 🔐 Безопасность

Программа предназначена для удаления скрытой служебной информации из файлов перед их передачей другим пользователям или публикацией в интернете.

> **Важно:** очистка метаданных не изменяет основное содержимое файла, однако рекомендуется создавать резервную копию оригинального файла перед обработкой.
